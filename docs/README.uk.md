# Документація keel

[English](README.md)

keel — це плагін, який планує, створює й незалежно перевіряє вашу роботу. Сьогодні він працює в Claude
Code; підтримку інших агентів для програмування заплановано. Огляд проєкту є в
[головному README](../README.uk.md).

З чого почати: прочитайте [Як працює keel](overview.uk.md), щоб побачити всю картину, один раз
пройдіть [Початок роботи](getting-started.uk.md), а далі користуйтеся іншими сторінками як довідкою.

## Почніть тут

| Сторінка | Що там |
|---|---|
| [Як працює keel](overview.uk.md) | Уся система на одній сторінці: три напрямки (задачі, сесії, планування), початок і закінчення роботи, звіт, передача, перевірка, делегування, git, що працює у фоні. |
| [Встановлення](install.uk.md) | Вимоги, встановлення й області встановлення, де діє keel і що він змінює, оновлення й видалення keel, усунення неполадок. |
| [Початок роботи](getting-started.uk.md) | Покроково: налаштувати проєкт, зробити першу задачу, передати задачу, продовжити довгу роботу, спершу спланувати фічу, прибрати. |
